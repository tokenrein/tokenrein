The problem

Agents spend money while nobody is watching.

One stuck agent can loop for hours.

The same tool call, the same prompt, over and over, each one billed. Provider spend caps are per account and trip after the money is gone.

The bill arrives a month later.

One invoice for the whole company. No answer to which team, which agent, which person or which task spent it.

Rolling out coding agents means trusting every laptop.

Hundreds of developers, each running Claude Code or Cursor with real keys and no limit per person or per session.

The product

Budgets that act before the spend, not after.

Budgets at every level

Per run, per agent per day, per project and org per month. Each one warns, blocks, or asks a person. Projects inherit the org's limits and can tighten them.

Approvals, not dead ends

When a run reaches its budget it pauses and asks an approver in Slack, Teams or the dashboard. Approve more budget and it carries on where it stopped.

Loop guard

The same request or tool call again and again, spend that suddenly races, too many calls in one run: the run is paused within minutes, not discovered next month.

Every agent, any model

One command connects Claude Code, Codex CLI, Gemini CLI or Cursor. One line wraps your Python or TypeScript client. Or use it as a base URL from any tool.

Prompts stay yours

By default agents call their model provider directly; Tokenrein only receives token counts and a hash of each request. Nothing to send through a third party.

Spend you can explain

Live agents, every run with its sub-agents, and spend by model, person, project and agent. Chargeback without spreadsheets.

How it works

From install to enforced in three weeks, without blocking anyone on day one.

  1. 1

    Connect

    Deploy with Docker Compose or Helm, sign in with your identity provider, and connect agents from the Connect page.

  2. 2

    Observe

    Apply a guardrail pack. Every limit starts in Check mode: nothing is blocked, and you see what would have been.

  3. 3

    Enforce

    Switch the limits you trust to Enforce or Ask, turn the loop guard on, and route alerts to the team that owns the agent.

Enterprise

Runs in your cloud. Answers to your security team.

Tokenrein is one stateless service with Redis and Postgres. Deploy it with Helm or Docker Compose next to your agents; your prompts, keys and usage data stay with you.

  • Single sign-on with Okta, Microsoft Entra ID, Google Workspace or any OpenID Connect provider, with roles from groups

  • Audit log of every change and decision, exportable and streamed to your SIEM

FAQ

Questions teams ask first.

Does Tokenrein see our prompts?

Not by default. With the SDKs and the coding-agent connectors, agents call their model provider directly and Tokenrein only receives token counts and a hash of each request. Only proxy mode passes calls through Tokenrein, and it does not store them.

What happens if Tokenrein is down?

Agents keep working: checks fail open by default, and usage is reported when Tokenrein is back. Orgs that prefer safety over availability can fail closed.

Will it slow our agents down?

A budget check is one round trip to Tokenrein and one atomic Redis operation; in proxy mode the overhead before the upstream call measured under 0.1 ms on a laptop.

Which models and providers?

OpenAI, Anthropic, Google Gemini, Mistral, DeepSeek, xAI, Groq, OpenRouter and other OpenAI-compatible providers, plus local Ollama, vLLM and LM Studio. Built-in prices can be overridden per model.

Can we try it without blocking anyone?

Yes. Guardrail packs start every limit in Check mode, and the dashboard shows exactly which requests Enforce would have refused before you switch.
