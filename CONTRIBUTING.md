# Contributing

Thanks for your interest in Tokenrein.

**Issues are very welcome:** bug reports, feature requests, questions and integration ideas. Use
the templates when you [open an issue](https://github.com/tokenrein/tokenrein/issues/new/choose).

**Code contributions are not accepted yet.** The server is offered under the Elastic License 2.0
with paid license keys, and accepting outside code needs a contributor agreement we have not set up.
If you have a fix, open an issue describing it and we will take it from there.

Security problems: see [SECURITY.md](SECURITY.md) instead of opening an issue.
